DAVID – GEBURTSTAGS-SEITE ❤️

1. Öffne index.html, um die Seite anzusehen.
2. Ersetze den Beispieltext und füge bei Bedarf Fotos hinzu.
3. Damit ein QR-Code von anderen Handys funktioniert, muss die Seite
   online unter einer öffentlichen Adresse liegen.
4. Sobald du mir die fertige öffentliche Adresse gibst, kann daraus
   ein QR-Code gemacht werden, der direkt auf die Seite führt.

Die Gestaltung ist pink und auf David als besten Freund zum Geburtstag
ausgelegt.
